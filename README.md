## 📌 Project Overview

The **AI Diet Planner** removes the guesswork from meal prep. Users input their health goals, preferred diet style, and any ingredient sensitivities or allergies. Leveraging LLM prompt constraints, the system crafts a structured 7-day meal plan and extracts a consolidated grocery list that users can export or print.

---

## ✨ Must-Have Features

1. **Profile Input Form:**
   - Collects personal fitness and health goals (e.g., weight loss, muscle gain, maintenance).
   - Captures diet types (e.g., Vegetarian, Vegan, Keto, Mediterranean).
   - Strict allergen and exclusion filtering (e.g., gluten-free, dairy-free, nut allergies).

2. **AI-Generated Weekly Meal Plan:**
   - Dynamically constructs a structured 7-day schedule (Breakfast, Lunch, Dinner, Snacks).
   - Strictly respects user dietary constraints and prompt rules.

3. **Grocery List Export:**
   - Aggregates ingredients across all generated meals into organized shopping categories.
   - Allows users to export (TXT/PDF/Clipboard) for shopping convenience.
